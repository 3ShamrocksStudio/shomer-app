מה אנחנו אוספים

SH✡MER אוסף את המינימום ההכרחי: מספר טלפון (לאימות בלבד — מאוחסן במערכת כגיבוב הצפנה חד-כיווני, hash, לא כמספר גלוי), שם תצוגה שבחרת, ומיקום — אך ורק כשאת/ה משתף/ת אותו באופן יזום (SOS או שיתוף מיקום).

התראת אדם נעדר / חטיפה

כשמשדרים התראה על אדם שקישרת, נשמרים בשרת: שם האדם, תמונה אם צירפת, תיאור ו"נראה לאחרונה", המיקום האחרון הידוע שלו בעיגול (כ-110 מטר), השעה, ומזהה החשבון של האדם (כדי שיוכל לסגור את ההתראה בעצמו). שמך מצורף רק אם הפעלת "הצג שם בעדכונים" בהגדרות (כברירת מחדל זה כבוי). מזהה החשבון שלך לא נכלל בהתראה: הוא נשמר ברשומה נפרדת שאף משתמש לא יכול לקרוא, רק כדי שתוכל/י לסגור אותה. (עד שעדכון שרת שאנחנו מבצעים ייכנס לתוקף, ייתכן שההתראה עדיין תכלול את מזהה החשבון שלך.)

מי רואה: כל המשתמשים המחוברים לאפליקציה, כדי שיעזרו בחיפוש. ללוח הקהילה עוברים רק סוג האירוע ונקודה מעוגלת (כ-1 ק"מ), בלי שם ובלי תמונה.

הסרה: את/ה או האדם יכולים לסגור את ההתראה ב"נמצא/בטוח", והיא נעלמת מהמפה לכולם. התראה סגורה מוסתרת מהאפליקציה אחרי 90 יום ונמחקת מהשרת (המחיקה האוטומטית תופעל עם עדכון שרת שאנחנו מבצעים). למחיקה מוקדמת יותר כתבו ל-support@shomer-app.co.il.

דפיברילטור (AED) שהוספת למפה

נשמרים בשרת: המיקום שבחרת, תיאור קצר והשעה. כל המשתמשים המחוברים רואים אותו, כדי שימצאו דפיברילטור בשעת חירום. מזהה החשבון שלך לא נכלל ברשומה: הוא נשמר ברשומה נפרדת שאף משתמש לא יכול לקרוא, רק כדי שתוכל/י לעדכן אותה. (עד שעדכון שרת שאנחנו מבצעים ייכנס לתוקף, ייתכן שהרשומה עדיין תכלול את מזהה החשבון שלך; באותו עדכון הוא יוסר גם מדפיברילטורים שהוספת קודם.) למחיקה כתבו ל-support@shomer-app.co.il.

שתי שכבות: SH✡MER ו-SH✡MER Nature

אפליקציה אחת, שתי שכבות. לחיצת SOS היא תמיד מצוקת אדם, ועוברת רק לשכבת SH✡MER: לאנשים שבחרת, למשתמשים בקרבת מקום ולשכבת האדם בלוח. אם אחרי השליחה סימנת שזה בעל חיים או מפגע סביבתי, האירוע עובר לשכבת הטבע, ומי שכבר קיבל התרעה רואה שזה דיווח טבע ולא מצוקת אדם. שריפת חורש מופיעה בשתי השכבות, עם התרעה אחת בלבד.

דיווח טבע (חיה פצועה, התעללות בבעל חיים, השלכת אשפה, זיהום, מפגע בשמורה, שריפת חורש): נשמרים בשרת סוג הדיווח, המיקום שלך בזמן הדיווח, השעה, הערה אם כתבת, ובשריפה גם תשובתך לשאלה אם היא ליד יישוב. מזהה החשבון שלך נשמר ברשומה כדי למנוע ניצול לרעה, ורק את/ה יכול/ה לקרוא אותה. שמך לא נשלח, אלא אם הפעלת "הצג שם בדיווחים".

מי רואה: ללוח הארגונים עוברים רק סוג האירוע, השכבה, השעה ונקודה מעוגלת (כ-1 ק"מ). בלי שם, בלי מזהה חשבון ובלי מספר טלפון. כל ארגון רואה רק את השכבות שהפעיל: שכבת האדם (למשל קב"ט, מועצה, רכז קהילה) או שכבת הטבע (רכזי שטח, מתנדבי טבע, גורמי סביבה). שריפה ליד יישוב, או כשלא ידוע אם היא ליד יישוב, מופיעה בשתי השכבות.

אימות SMS מתבצע באמצעות Twilio; אחסון נתונים מאובטח ב-Google Firebase. שניהם כפופים לתקני אבטחת מידע בינלאומיים.

זכויותיך

ניתן לבקש עיון, תיקון או מחיקה של המידע שלך בכל עת דרך support@shomer-app.co.il.

Two layers: SH✡MER and SH✡MER Nature

One app, two layers. An SOS is always a person in distress and goes only to the SH✡MER layer: the people you chose, users nearby, and the person layer of the dashboard. If, after sending, you mark it as an animal or an environmental hazard, the event moves to the Nature layer, and anyone already alerted sees it is a nature report, not a person in distress. A forest fire appears in both layers, with one alert only.

Nature reports (injured animal, animal abuse, dumping, pollution, a hazard in a reserve, forest fire): the server stores the type, your location when you reported, the time, a note if you wrote one, and for a fire your answer to whether it is near a settlement. Your account id is kept in the record to prevent abuse, and only you can read it. Your name is not sent unless you turned on "show name on reports".

Who sees it: the organisations' dashboard gets only the event type, the layer, the time and a rounded point (about 1 km). No name, no account id, no phone number. Each organisation sees only the layers it turned on: the person layer (for example a security officer, a council, a community coordinator) or the Nature layer (field coordinators, nature volunteers, environmental bodies). A fire near a settlement, or where it is not known, appears in both layers.

Missing person / abduction alerts

When you broadcast an alert about someone you linked, the server stores: their name, a photo if you add one, a description and "last seen", their last known location rounded to about 110 m, the time, and their account id (so they can close the alert themselves). Your name is attached only if you turned on "Show name in updates" in Settings (off by default). Your account id is not in the alert: it is kept in a separate record that no user can read, only so you can close it. (Until a server update we are rolling out takes effect, the alert may still carry your account id.)

Who sees it: all signed-in app users, so they can help search. The community dashboard only gets the event type and a rounded point (about 1 km), with no name or photo.

Removing it: you or the person can close the alert with "Found / safe", and it disappears from the map for everyone. A closed alert is hidden in the app after 90 days and deleted from the server (automatic deletion starts with a server update we are rolling out). To erase it sooner, write to support@shomer-app.co.il.

Defibrillators (AEDs) you add to the map

The server stores the location you chose, a short description and the time. All signed-in users see it, so they can find a defibrillator in an emergency. Your account id is not in the record: it is kept in a separate record that no user can read, only so you can update it. (Until a server update we are rolling out takes effect, the record may still carry your account id; the same update also removes it from AEDs you added earlier.) To erase one, write to support@shomer-app.co.il.
